# Free local speech practice scorer

The application uses a local acoustic phoneme recognizer, not text transcription similarity. No commercial speech account, API key, or external audio upload is required. Recordings are held in request/page memory and are not written to files, logs, the database, or backups.

Model: [Meta Wav2Vec2-XLSR-53 eSpeak](https://huggingface.co/facebook/wav2vec2-xlsr-53-espeak-cv-ft), Apache-2.0, exported as ONNX fp32 by [iwillsolvehardestproblem](https://huggingface.co/iwillsolvehardestproblem/wav2vec2-xlsr-53-espeak-cv-ft-onnx), revision `1bc86aec48933fdced56df9e16bc132152d208e8`. The installation loads only ONNX and JSON data; it does not execute model-repository Python code. Model vocabulary is 392 phoneme tokens and audio input is 16 kHz. The fp32 file is about 1.26 GB. SHA-256: `47a8eeaf32baa9de1310f387b23dc07d6f7c362d2b9d6bf87fad7ad2df84cafb`; vocabulary SHA-256: `3768692b2b3c85b12c0608181dface0544d99e5ead0c76d22c94e8bf97251164`. Assets and the isolated Python environment live in `/home/ubuntu/.local/share/games-speech`, outside the web document root and Git repository.

`GET /api/english/speech-status` checks actual local model health, caching results for five seconds. `POST /api/english/pronunciation?target=<known-page-target-id>` accepts 16 kHz, 16-bit, mono PCM WAV lasting 0.15–20 seconds. It requires the public origin and resolves authoritative textbook text on the server. Client reference overrides are ignored. The Python HTTP server binds to `127.0.0.1:8769`; its reference text is sent only by the application server.

The recognizer decodes whole recordings once, with 100 ms padding at each end, to preserve sentence context. eSpeak NG `en-us` produces contextual reference phonemes (printed source IPA overrides isolated homographs such as `read` and `use`) and a dynamic edit alignment associates them with printed words. English vowel length marks are normalized while vowel qualities stay distinct. `score` and `accuracy` are the same phoneme edit similarity percentage: `100 × max(0, 1 − edit_distance / max(reference_tokens, heard_tokens))`. `completeness` counts reference phoneme positions paired with any heard phoneme. Word scores count matching phonemes divided by the larger expected/heard count for that aligned word. These are automated practice feedback, not calibrated professional pronunciation probabilities. Proper names, accent variation, and very short words can be uncertain; a standard recorded example is not always scored 100. No fluency metric is invented.

RMS/active-signal checks and empty phoneme output reject quiet/no-speech audio with HTTP 422. HTTP 503 means unavailable and HTTP 429 means busy or rate limited. The application bounds one concurrent inference, six requests per IP per minute, and 1,000 requests globally per UTC day. Rate state is held in memory and resets on platform restart. Python also serializes inference; ONNX uses four intra-operation threads and one inter-operation thread. systemd caps memory at 4 GB and CPU at 300 percent.

## Install or recover

1. Install Ubuntu `espeak-ng`. Create `~/.local/share/games-speech/venv` with `python3 -m venv` and install `speech-requirements.txt` in that environment.
2. Download only `model.fp32.onnx` and `vocab.json` from the pinned ONNX model revision above into `~/.local/share/games-speech/model`. Save the repository/revision in `model/provenance.json`. Verify downloaded hashes against deployment evidence before activation.
3. Copy `speech_inference.py`, `speech_reference.py`, and `speech_scoring.py` to the runtime directory. Install `deploy/games-speech.service` in `/etc/systemd/system`, run `systemctl daemon-reload`, then `systemctl enable --now games-speech`.
4. Check `curl -fsS http://127.0.0.1:8769/health`. Evaluate actual standard speech, different-word speech, silence, and noise. The evidence artifact contains measured values; health alone does not establish scoring quality.
5. Add `SPEECH_LOCAL_URL=http://127.0.0.1:8769` to the private platform `app.env`. Deploy the application and nginx pronunciation location, then restart its platform service. Keep this environment file private and outside the web root.

Run `node --test tests/pronunciation.test.mjs`, `python3 tests/pronunciation-scoring.test.py`, and `python3 tests/pronunciation-reference.test.py`. The final reference regression requires `espeak-ng`; run it on the speech host if absent locally. Live evaluation uses already-published textbook TTS fixtures, not child recordings or fabricated parent accounts.
