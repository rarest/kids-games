# 微信英语小课堂

用微信开发者工具导入本文件夹（`miniprogram/`）。`project.config.json` 默认 `touristappid`；可浏览原生页面结构，真实微信登录需要正式小程序 AppID。

客户端只配置 `config.js` 的 HTTPS 网站地址；AppSecret 与微信 session_key 只在服务器。课程 JSON、音频和插图远程加载，主包不包含全量教材。原生页面包括课程首页、导学课、逐页课堂和家长账号。

正式配置顺序：

1. 注册小程序并取得 AppID，在本地开发者工具改 AppID。已有公众号的 AppID 不能直接当作小程序 AppID。
2. 在服务器设置 `WECHAT_MINI_APP_ID`、`WECHAT_MINI_APP_SECRET`，重启家庭 API。确认 `/api/miniprogram/config` 的 `wechatReady` 为 `true`。
3. 在小程序后台配置 `https://games.nblord.com` 为 request 合法域名；音频、图片也使用这个 HTTPS 域名。开发预览可临时关闭域名检查，真机验收和发布需恢复检查。
4. 完善《用户隐私保护指引》，声明麦克风、主动提交录音和孩子档案用途，核对平台的用户隐私确认流程。录音入口依次调用隐私授权及 `scope.record` 授权。录音为最长20秒、16kHz、单声道 WAV；点击提交才发送，不在客户端模拟评分。
5. 在 iOS、Android 真机核对访客学习、用户名登录、真实 `wx.login`、选择两个孩子、微信关联冲突、返回页面、拒绝麦克风授权、切后台中断录音、回听、提交反馈及登出。录音临时文件在离开页面/切换目标时丢弃；先确认平台实际删除行为。
6. 核对中文名称、类目、内容、隐私说明和域名备案要求，提交平台审核，再发布。

进度规则：导学课沿用网站 `version:1` 结构、答题事件和完成事件。错后重试允许继续，但首次答错仍进入复习记录。登录后每个孩子独立保存；云端冲突由家长选择课堂位置，答题事件保留并合并。已验证过的孩子档案可在离线时恢复此设备记录；恢复网络后再同步。此设备访客导学进度只可显式导入空白孩子档案。逐页练习记录按孩子保存在此设备；跟读反馈仅用于练习。

测试：在仓库根目录运行 `node --test tests/miniprogram-client*.test.mjs`。测试以注入的微信端口及原生 Page VM 执行真实事件，教材数据来自远程资源的本地构建产物。它们验证客户端逻辑；开发者工具真机授权、麦克风、腾讯 code 交换、平台审核仍需正式 AppID 后完成。
