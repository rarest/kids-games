# 射击游戏与游戏厅三端适配

用户已授权自主设计、开发并沿用现有游戏站发布。新射击游戏采用太空机器人主题，自动开火、拖动/方向键移动、三点护盾、逐关挑战、三选一升级、暂停和本机最高分。游戏无需账号、付费或外部运行时。

1. 新建 `shooter/core.js`：独立模拟、碰撞、分段时间推进、关卡生成、升级和尺寸变换。先写 `tests/shooter-core.test.mjs`，检查命中只计分一次、护盾/无敌时间、关卡与升级、不同帧率一致性、旋转后物体留在画面中。
2. 新建 `games/shooter.html`、`shooter/game.js`、`shooter/style.css`：动态尺寸画布与有上限的分辨率，Pointer Events 和方向键，隐藏页面自动暂停，关卡升级和历史纪录。加到 `games.js`。
3. 三端适配：打字键盘和游戏区域随屏幕放大；蛇按真实容器与控制区尺寸计算正方形；大鱼、迷宫、矿工、合成4096解除不合适的宽度上限并增加低高度布局。捕鱼已有全屏布局，核查即可。
4. 浏览器回归 `tests/responsive-browser-smoke.mjs`：手机竖横屏、平板竖横屏、电脑，检查八游戏实际画面、控制区、溢出和旋转；检查新游戏启动、拖动、暂停恢复和纪录。
5. 执行项目完整测试，调用独立代码审查，修复实际问题，再合并部署；核对生产文件和公共浏览器路径。报告和截图保存到现有 output 目录。
