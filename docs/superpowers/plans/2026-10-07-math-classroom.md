# 数学课堂实施计划

Goal: 依据用户提供的全册照片交付可用的数学互动教程。

Architecture: math 目录的课程、纯运算模型、学习引擎、互动视图；复用既有家长 API、语音鼓励与课堂导航。学科云端 codec 单独验证数学记录。

Tech stack: ES modules、SVG、CSS、esbuild、Node test、Chromium CDP、PostgreSQL。

Spec: ../specs/2026-10-07-math-classroom-design.md

Global constraints: 不公开照片与个人身份；不盲信手写；不影响三科原有档案；精确教学图不能靠 AI 图片表达答案；教材活动独立标识；不擅自改品牌。

1. 教材内容与模型：先写有答案核查的课程/模型测试，再实现全册小课与数学运算模型；记录页码与教学目标。
2. 学习与云端：先测伪造步骤、首次错误后重试、完成证据、复习隔离，再实现数学引擎/家庭模块/backend codec 与 allowlist；隔离数据库验证。
3. 互动页面：实现不同单元的操作组件、朗读与鼓励、适配手机平板桌面；入口与学科导航启用数学；原生输入浏览器测试首次学习、错题、刷新续学、目录与所有操作。
4. 交付：独立代码与教学审查；修复发现；相关回归、构建、合并、部署、公开页面验证，报告真实范围与链接。
