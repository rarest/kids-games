# 微光跑酷 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付并部署包含12关、教程、皮肤商店与自创关卡的自由移动3D跑酷。

**Architecture:** 纯逻辑模块负责物理、关卡、存档及编辑数据，Three.js 场景只展示同一数据。界面负责模式、输入和持久化，打包为本站资源；不改已有游戏实现。

**Tech Stack:** ES modules、Node test、Three.js 0.186.1、esbuild、现有 Chromium CDP harness。

**Spec:** openspec/changes/3d-platform-parkour/specs/parkour-game/spec.md；设计见同目录 design.md。

## Global Constraints

- 四主题12关，自由移动模式 B，不自动向前跑；第一关有教程。
- 方向键/WASD移动相对镜头；空格或画布单击跳跃；鼠标拖动旋转镜头，拖动释放不触发跳跃；触屏独立摇杆及跳跃按钮。
- 红色默认免费；橙黄绿青蓝紫黑粉棕深蓝深绿和彩虹每款2金币；同局金币只能领一次，重新开始预设关卡可重领；自创金币不增加余额且界面解释。
- 主页火柴人有笑容、待机活动，点击跳跃；已装备颜色在主页和游戏一致。
- 复用已有锁定版本 Three.js 0.186.1，本地打包，不使用外部CDN；不修改其他游戏模块。
- 编辑器最多80个平台，起点终点必须有支撑；保存重载试玩，非法数据不能崩溃。
- 暂停/隐藏/失焦清空输入，停止物理；场景切换释放旧资源，像素比最高1.5、阴影1024、有限特效。
- 使用 apply_patch 修改文件。主线基线4e3d2af，独立工作树 .worktrees/parkour，禁止发布别的工作树改动。

### Task 1: 纯逻辑、关卡与存档编辑数据

**Files:** Create `parkour/core.js`, `parkour/levels.js`, `parkour/profile.js`, `parkour/editor.js`; tests `tests/parkour-core.test.mjs`, `tests/parkour-profile.test.mjs`, `tests/parkour-editor.test.mjs`.

**Interfaces:**
- `LEVELS`: 12个 level `{id,name,theme,difficulty,platforms,spawn,goal,coins,checkpoints,tutorial}`；theme 是 `sakura|flowers|city|cabin`。
- 平台 `{id,x,z,y,w,d,h}`，y 是顶面高度，h 是实体厚度；点 `{x,y,z}`；金币和存档点另有id。角色 y 是脚底，身高 `PLAYER_HEIGHT=1.65`、半径 `PLAYER_RADIUS=0.25`。
- `createState(level)` 返回 `{level,player:{x,y,z,vx,vy,vz,yaw,grounded},checkpoint,collected:Set,events:[],elapsed,complete,falls,tutorial}`。
- `stepState(state,{x,z,jump},dt)` 原地更新并返回state，每次刷新events；事件 `{type:'coin'|'jump'|'land'|'checkpoint'|'fall'|'finish',id?}`。输入x/z是世界方向，归一化斜向，移动速度6，起跳8.4，重力20；使用≤1/120秒分步，单帧最多0.25秒，缓冲跳/离台容错0.12秒；长按跳跃不自动连跳。金币收集半径0.6，终点和存档点在正确高度且落地时触发，复位保留collected。
- `SKINS`: 13款 `{id,name,color,price}`，红色 `red` 免费，彩虹 `rainbow` 动态颜色。
- `createProfile(raw?)`、`buySkin(profile,id)`、`equipSkin(profile,id)` 原地更新并返回boolean；`creditCoin(profile,state,coinId)` 每个state收据一次，仅预设可支付；`recordFinish(profile,state)` 保存最佳和通过状态；`readProfile(storage)`、`writeProfile(storage,profile)`，键 `glow-parkour-v1`，写失败返回false；不得改其他游戏键。
- `createEditorLevel()` 返回可试玩两平台样例；`validateLevel(raw)` 返回 `{ok,errors,level}`，仅保留支持字段，拒绝非有限数值、重复id、超过80平台及无支撑起终点；`readEditorLevel(storage)` 和 `writeEditorLevel(storage,level)`，键 `glow-parkour-level-v1`；错误不冒泡，UI能判断失败。
- `tutorial` 初始化为 `{moved:false,jumped:false,camera:false,collected:false,checkpoint:false,finished:false}`；core负责除camera外的进展。

主题须有视觉区别：樱花树分枝与花瓣、花林花丛、城市楼房窗户道路及移动汽车/天桥、木屋屋顶和树木；地图平台要能看清边界和落点，光照与阴影，终点门明显，落点影子，角色有四肢运动和笑脸。环境几何合并/实例化以控制draw calls，有限运动装饰。主页可围绕人物展示首关景色，文字面板不能完全遮住人物。画布单击只在home/playing触发跳跃，不允许商店模态背后移动；拖动和单击区分，click释放坐标不可遗失。相机近平台避让与复位。

教程按真实进展显示当前一条，并可查看完整操作帮助或跳过提示，完整含镜头/移动/跳跃/金币/存档点/终点；不强迫镜头拖动阻止通关。简单跳跃/金币/落地音效可静音，用户首次操作解锁，静音及暂停生效。

编辑器使用足够大的俯视可缩放预览；点击空处放平台，点击平台选择；可修改 x/z/y/w/d，删除不导致无反馈崩溃；工具设置spawn/goal/checkpoint/coin，自动在相应支撑平台取顶面y；保存加载状态明确，自创金币不计余额提示；试玩后可回编辑继续。不要把固定样例关卡按钮当编辑器。
