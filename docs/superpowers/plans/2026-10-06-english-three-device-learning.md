# 英语课堂三端交互改版计划

目标：让三年级儿童在手机、平板、电脑上明确知道当前学习动作、短组终点与如何继续，保留照片教材、完整题库与真实反馈。

范围与设计：
- 手机 <=650px：单列学习内容，触控操作置于可达区域，保留安全区和正文空间。
- 平板 651—1100px：触控优先、支持横竖屏，辅助内容不能把题卡推到很远。
- 电脑 >1100px：目标与目录侧栏、学习内容主栏，清晰行距；模态固定头部不能覆盖课文。
- 导学长阅读每组4句，按原顺序、原行号；当前组听读、上一组、全文听读仍可访问。
- 逐页题库每组6题，组末有真实完成状态与继续/暂停；保存每孩子的页内续练位置；最后一组不能偷偷循环首题。
- 录音按状态显示当前操作，提示靠近操作；无录音不展示得分；只有显式提交才上传；完整分数和家长提示仍可展开。

实施与验证：
- [x] UI与儿童学习两个独立审计，量化长段21句与逐页258题等现状。
- [x] 导学分组与三端操作：course-ui.js/course.css，真实鼠标/触摸播放和source target检查。
- [x] 逐页短组、续练与模态布局：page-classroom.js/css、page-practice-progress.js，验证题库ID不变、暂停恢复、完整组终点。
- [x] 录音流程：speaking.js/css，先失败检查缺录音前得分按钮隐藏，再验证真实麦克风录音与显式提交；相关7项通过。
- [x] 统一构建bundle、加入相关测试入口、独立代码审查。
- [ ] 合并部署、公共资源核对、三端公网交互检查。
