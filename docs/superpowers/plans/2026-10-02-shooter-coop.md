# 星际小队联网合作

用户已明确要求多台手机/电脑通过互联网加入同一队伍合作，沿用自主设计、实现、测试、发布授权。采用最多16人、邀请链接或队伍码、服务器统一模拟的WebSocket方案；不要求同一个Wi-Fi。单人继续本地运行。保留刚合并的声音功能。

最新关卡（以最新语音为准）：200大关，每大关50小关；第二大关第一小关（51）20个随机大Boss。第一、二小关各1个最弱黄色Boss和红色小怪，前9小关只有黄色Boss，10–19小关可出现蓝色，20起紫色加入随机池；第一大关第30小关固定10只紫Boss。后续关卡血量递增、敌人数逐渐增加，Boss分批进入，碰撞统一1点，子弹基础伤害红1/黄3/蓝4/紫10；Boss每大关+1最多+5，多人再+1；多人血量每额外队员+8%最多+60%；扩散100上限。

实现：
1. 先补单元测试，核心支持独立玩家生命、装备、输入和射击；共享敌人/积分/关卡。队友战败观战，过关复活；全部战败允许队长重试当前关。每人独立抽卡，在线队员都抽卡后由队长进入下一关。
2. 新增有房间容量/消息上限/闲置回收的Node WebSocket服务，统一30Hz模拟、15Hz状态，客户端60Hz插值。房主离开随机转交给在线队员；网络中断显示可重连入口，同一会话短时间内保留座位，自动暂停避免无人操作。
3. 页面创建/加入/邀请/队员/退出、触控和键盘操控，统一逻辑坐标，按屏幕缩放，保留单人存档。服务器不信任客户端生命/分数/关卡，只接收输入与动作。
4. 通过独立浏览器实例实际验证双方视角、操控、技能、离开/重连/无效队伍、布局；服务器协议测试房间隔离与限制；原相关测试回归。独立审查。
5. 沿现有源站增加仅监听本机的服务和WebSocket代理，验证配置后reload。通过真实公网地址两浏览器验证后交付。

完成记录：核心和协议已覆盖16人容量、独立操控/技能/抽卡、房间隔离、仅输入可写、断线重连、旧空队失效、队长退出随机继承。真实双浏览器已测跨手机/电脑视角、双方同步移动/激光、拖动切回键盘、共享暂停、断线重连、邀请链接进入及队长交接。独立审查发现并修复空大厅复用退休队长、拖动目标阻挡键盘、最后存活队员离开导致卡关，复审通过。全项目测试正在收尾，随后合并、部署、双公网浏览器验收。
