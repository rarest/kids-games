# 峰谷竞速 Implementation Plan

**Goal:** Deliver a playable, public 3D racer with 10 opponents, winding mixed-terrain tracks, realistic styled cars, reflective skins, shadows, and podium-only rewards.
**Architecture:** Pure deterministic race/track/economy logic in `racing/core.js`; locally bundled Three.js renderer in `racing/scene.js`; responsive controls and garage in `racing/game.js` and `games/racing.html`. No external CDN or server calculation for racing.
**Tech Stack:** JavaScript, Three.js 0.186.1, esbuild, Node test runner and isolated Chromium CDP.

## Requirements
- Player plus ten AI opponents, two laps. Only first / second / third receive 3000 / 1500 / 700 game coins.
- Six routes including a mixed circuit through plateau, mountains, abandoned factories/roads and busy highway; five other routes emphasize each setting.
- Four distinct car silhouettes and six skins, including changing iridescent patterns. Real geometric cars, PBR reflective paint, sunlight, shadows, grass, buildings and traffic.
- Keyboard and touch controls, automatic throttle option, braking and rechargeable nitro. Pause when backgrounded. Garage purchases/equipment persist locally.
- Cap resolution, instance repeated roadside objects, share geometry/materials, maintain existing games.
