# 双人联机卡顿修复

用户要求直接改善已上线《星际小队》双人联机。基于最新main，保留关卡、伤害、抽卡、16人队伍、声音和领地游戏。

复现与根因：扩散升至100时双人约700发存活子弹，旧每次快照仅子弹约17KB，每秒15次，每人约2Mbps；16人约134KB/快照。服务器对同一房间重复JSON序列化。自己的飞机直到收到服务器坐标才开始移动；旧版在模拟上行200ms/下行400ms的浏览器测试中响应675ms。

改动：
- protocol2按一轮齐射的原点、速度、数量和存活位图同步，客户端精确重建每道存活子弹；服务器仍处理完整子弹碰撞。旧协议可并存。
- 同房同协议只序列化一次；慢连接跳过积压中的旧快照，下一次用最新状态。
- 本机飞机立即移动，停止后等待服务器确认最新输入再平滑校正；敌人平滑，HUD10Hz，子弹批量绘制。
- 方向改变即时发送；连续拖动33ms合并，稳定输入100ms心跳且保持同sequence，防止高刷设备超过服务器限额。

验证记录：精确子弹/被命中后位图重建，2/8/16人满扩散子弹数据分别减少95.6/95.5/95.2%；延迟测试新版本一帧内响应并在停止后回归服务器位置。144Hz输入回归原144条/秒失败，修后<=35条且方向即时。原双浏览器联机、重连、邀请、队长交接、激光、战役、旧协议/新协议混合测试已通过。全项目及独立审查继续执行，完成后沿现有部署链上线，公网复测。
