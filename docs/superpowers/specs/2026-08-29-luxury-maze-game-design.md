# 豪华卡通迷宫游戏设计

日期：2026-08-29

## 目标

为“小火箭游戏厅”新增手机优先的华丽卡通游戏“皇冠迷宫”。玩家控制带表情和阴影的红色圆点小人，完成 10 个普通迷宫和穿插其中的 9 个奖励迷宫，共 19 个固定、手工设计且背景各不相同的关卡。所有迷宫必须收齐钥匙才能开门；普通关逐步变得庄严复杂，奖励关更温馨、更高大、更辉煌闪耀。

## 旅程结构

完整路线严格交错：

`普通1 → 奖励1 → 普通2 → 奖励2 → … → 普通9 → 奖励9 → 普通10`

- 普通关按顺序解锁。已通过的普通关可以从关卡地图直接重玩。
- 奖励关不能从关卡地图直接重玩。想再次进入某个奖励关，必须选择“重新开始旅程”，从普通第 1 关沿完整路线一路玩到该奖励关。
- 重新开始旅程只重置当前路线位置，不清空金币余额、道具库存、皮肤、普通关成绩或永久金币收集记录。
- 关卡地图显示 19 个节点：当前节点发光，未解锁节点显示闭锁，已通过节点显示开锁、关卡编号和成绩；已通过奖励节点点击后提示重新进入规则。

## 普通迷宫规则

- 使用固定在屏幕底部的虚拟方向键，支持点按走一格和长按连续移动。
- 玩家在网格中上下左右移动，不能穿墙；每次移动有平滑过渡和轻微弹性。
- 普通第 N 关恰好包含 N 个钥匙死角和 N+1 个空死角，共 `2N+1` 个死角。
- 顶部显示 N 个钥匙槽位和 `已收集 X / N`：未收集为暗色轮廓，已收集为发光金色。
- 出口默认锁定。未集齐时到达出口显示“还差 X 把钥匙”；全部收齐后再次到达出口才开门。
- 不设倒计时。记录用时和步数；星级按步数相对最优路线计算：不超过 125% 为 3 星，不超过 175% 为 2 星，其余为 1 星。

## 奖励迷宫规则

- 9 个奖励关都是不同的固定、手工迷宫，并从简单逐步变难。
- 奖励第 N 关包含 N 把钥匙和 N+1 个空死角；钥匙必须全部收齐才能开出口。
- 金币不影响开门，可以少拿并沿原路返回补拿。
- 奖励第 N 关金币数为 `5 + 3×(N-1)`，依次为 5、8、11、14、17、20、23、26、29，总计 153 枚。
- 每枚金币按“奖励关编号 + 金币位置”永久独立记录。已经取得的金币再次进入时不出现，漏掉的金币仍保留，不能通过重玩重复领取。
- 拾取金币时金币旋转炸开，释放星星点点的金色碎光和光圈，并播放轻微清脆的真实录制金币声。

## 道具商店与迷宫道具

- 炸药售价 1 金币，钩子售价 3 金币。每次购买增加一个库存，库存可以累计，两者都是一次性消耗品。
- 使用炸药：点击炸药按钮后按一个方向，炸掉角色相邻的一面可破坏内墙。迷宫外墙、出口结构和关键保护墙不可破坏；无合法目标时不消耗。
- 使用钩子：点击钩子按钮后按一个方向，越过 1～2 面连续墙并落在墙后的第一个安全通行格；没有安全落点时不消耗。
- 道具只改变路线，不能代替钥匙。每关仍必须取得全部钥匙。
- 道具栏在主页和关卡 HUD 中显示金币、炸药和钩子库存。
- 每张地图在不使用道具时也一定可以正常通关。

## 皮肤商店

- 默认红色皮肤免费。
- 普通皮肤包括橙、黄、绿、青、蓝、紫、粉，每个售价 1 金币；购买后永久拥有。
- 三个隐藏皮肤在未达条件时完全不显示，通过对应普通关后才在商店显现，并各花 3 金币购买：
  - 通过普通第 1 关：银色流光。
  - 通过普通第 5 关：金色星辉。
  - 通过普通第 7 关：炫彩琉璃彩虹。
- 隐藏皮肤具有专属粒子、光晕和移动拖尾；已购买皮肤可随时免费切换。
- 当前皮肤在主页显示动态预览，并应用到关卡内角色。

## 视觉与动效

- 使用 Canvas 矢量绘制迷宫主体，不使用简单贴图拼装墙体。
- 必须大量使用分层色块与阴影：墙体由深色投影块、主题主色块、金属边缘色块、顶部高光和角部雕花组成；地面以柔和大色块区分区域，并叠加渐变阴影。
- 人物、钥匙、金币、出口、商店卡片和按钮均具有接触阴影、投射阴影、高光和发光层，不能呈现扁平效果。
- 红色圆点小人具有眼睛、表情、高光、软阴影和移动弹性；撞墙时压缩回弹。
- 钥匙使用金色渐变、旋转和光粒；收集时产生金色粒子、扩散光圈和顶部钥匙栏点亮动画。
- 出口由宝石、金边、锁链、锁孔和光晕组成。收齐钥匙后锁链消失并播放开门动画。
- 奖励关道路在视觉上更宽阔、高大、温暖，使用暖色光晕、金色投影、宝石高光和持续星屑，但迷宫逻辑仍逐关复杂。
- HUD 使用半透明玻璃色块、细金边和投影；虚拟方向键使用立体宝石色块并适配手机安全区域。

## 真实录制音效

- 使用原创或许可明确的 CC0 真实录制音频文件并压缩为移动端格式，不使用实时合成音效。
- 每移动一格播放很轻但可辨识的“嗒”声；连续长按时形成柔和脚步节奏，且不能重叠爆音。
- 每次碰墙播放轻微短促的“咚”声，并与压缩回弹同步。
- 金币、钥匙、锁门、开门、购买、炸墙和钩索各有独立录制音效。
- 音效默认开启但音量克制；主页和暂停菜单提供声音开关。页面第一次触摸后再初始化音频，以符合手机自动播放限制。

## 页面与流程

1. 主页在进入游戏前显示角色动态预览、“开始游戏”和“商店”，并提供声音开关、金币和道具库存。
2. 商店以并列入口进入“道具商店”和“皮肤商店”。
3. 点击开始游戏进入 19 节点关卡地图。普通关可按解锁规则进入；奖励关按旅程规则进入。
4. 关卡 HUD 显示关卡名、钥匙槽位、金币余额、道具库存、步数、计时和菜单。
5. 收齐钥匙并到达出口后显示通关面板；普通关显示星级、步数、时间与下一节点，奖励关显示本次/总金币收集进度。
6. 普通第 10 关完成后显示皇冠庆典、普通关总星数和永久金币收集总数。

## 技术结构

游戏以静态 HTML/CSS/ES 模块部署到现有游戏站点：

- `games/maze.html`：页面骨架与无障碍标签。
- `maze/game.css`：主页、商店、地图、HUD、方向键和弹层样式。
- `maze/levels.js`：19 张固定地图、主题、类型、起点、出口、钥匙、金币和推荐步数。
- `maze/engine.js`：移动、碰撞、钥匙、金币、出口、道具、计时、星级和旅程规则，不依赖 DOM。
- `maze/economy.js`：购买、库存、皮肤显示条件、装备和永久金币记录。
- `maze/render.js`：Canvas 主题绘制、镜头、阴影、色块、粒子和动画。
- `maze/audio.js`：录制音频加载、解锁、音量、节流和播放。
- `maze/main.js`：输入、页面状态、存档和模块协调。
- `maze/audio/`：压缩后的脚步、碰墙、金币、钥匙、开门、炸药和钩索音频。
- `games.js`：新增“皇冠迷宫”游戏厅入口。

地图采用显式网格数据。墙为不可通行格，路为可通行格；起点、出口、钥匙和金币使用独立坐标。道具可破坏墙使用独立标记，避免误破坏边界或关键结构。

## 地图验证

构建测试必须逐关验证：

- 19 张地图的布局签名互不相同。
- 从起点在不使用道具时能到达所有钥匙和出口。
- 普通第 N 关和奖励第 N 关均恰有 N 把钥匙、N 个钥匙死角和 N+1 个空死角。
- 奖励第 N 关金币数严格等于 `5 + 3×(N-1)`，所有金币位置唯一且可达。
- 每把钥匙位于不同死角；起点和出口不计入死角。
- 收齐钥匙前出口不可通关，收齐后可以通关；金币数量不影响奖励关开门。
- 地图外围封闭，不存在越界移动；可破坏墙不会破坏地图边界或产生非法落点。
- 钩子跨墙落点合法；炸药与钩子在无合法目标时不消耗。
- 推荐步数不小于算法计算出的最短收钥匙并到达出口步数。

## 存档与异常处理

- 使用版本化 `localStorage` 保存普通关解锁和成绩、当前旅程位置、永久金币位置、余额、道具库存、皮肤购买/装备和声音设置。
- 金币拾取与购买使用先验证后保存的原子更新，余额不足时不能购买，刷新页面不会重复加币或重复扣币。
- 存档字段缺失时补默认值；类型错误、负余额、版本不兼容或 JSON 损坏时恢复到安全默认值并保留可验证字段。
- 页面切到后台时暂停计时和音效，返回后继续，避免切换应用影响成绩。
- Canvas 尺寸变化时重新计算缩放和镜头，不重置当前关卡状态。
- 所有代码、样式和音频资源使用版本参数，避免 CDN 或手机浏览器继续运行旧资源。

## 测试与验收

- 单元测试：19 张地图验证、移动碰撞、长按节流、钥匙/金币、锁门、旅程、星级、道具、商店、皮肤条件和存档迁移。
- 经济测试：153 枚金币位置唯一且只能获得一次；炸药扣 1 金币、钩子扣 3 金币、普通皮肤扣 1 金币、隐藏皮肤满足关卡条件后显示并扣 3 金币。
- 集成测试：从主页进入商店和关卡地图；使用方向键移动；验证暗色钥匙变金；验证金币粒子与余额；验证锁门、开门、炸墙、钩索和皮肤切换。
- 旅程测试：普通关可直接重玩；奖励关不能直接重玩；从普通第 1 关按路线可再次抵达奖励关，且已取得金币不重复出现。
- 音频测试：首次触摸后才解锁；走路、碰墙与拾取调用正确录音；连续移动不产生音频堆叠。
- 视觉验收：390×844 和常见平板尺寸下检查 19 个不同背景、HUD、安全区域、镜头、分层色块、阴影和按钮触控范围。
- 性能目标：中端手机保持流畅动画；Canvas 设备像素比上限为 2，粒子数量设硬上限，离屏装饰只绘制视口附近区域。
- 上线验收：游戏厅出现新入口，全部资源返回 200，浏览器控制台无异常，并核对公网文件与部署版本一致。

## 明确不做

- 不加入联网排行榜、账号、广告、内购或服务器端存档。
- 不加入敌人、生命值、倒计时、战斗或随机地图。
- 不使用位图素材包替代迷宫主体视觉；仅真实录制音效作为外部媒体资源。
