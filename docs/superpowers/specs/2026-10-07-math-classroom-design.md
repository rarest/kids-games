# 数学课堂：教材与教学设计

已核对：人民教育出版社《数学 三年级上册》，2025 年 6 月第 1 版，2026 年 7 月第 1 次印刷，ISBN 978-7-107-38914-6。用户三批 56 张照片覆盖正文 1—103 页、版权与附页。照片仅作阅读依据，不公开原图、姓名、手写答案或个人信息。

课程对应观察物体 1—5、混合运算 6—19、毫米分米千米 20—30、曹冲称象与质量 31—38、多位数乘一位数 39—56、数字编码 57—60、线和角 61—72、分数 73—91、复习与关联 92—103（包含搭配）。活动单元与教材编号区分。

每节小课：生活问题 → 操作探究 → 方法与原因 → 六道独立练习（含迁移）→ 自己说一说 → 回顾。图形与数轴由程序精确绘制，插画只作装饰。等分必须等量，比较分数使用相同整体；一组物体的分数先平均分组再计数；同分母加减解释单位分数。乘法展示数位与进位；几何变化不改变概念。屏幕尺不声称真实厘米。数字编码只用虚构样例。

数学在既有珠珠课堂网站上线，三科导航与同一家庭档案复用；英语小程序保持其现有范围。访客即开即学，网络失败不阻塞。首次答题独立于重试；提示使用不可通过收起提示抹掉；已学内容按北京时间安排复习。云端重建已发布题目与答案、验证完整完成证据、隔离孩子及学科。离开、换科、刷新保存，音频停止；重复正确点击不重复记分。

内容接口：`COURSE={edition,units:[{id,number,title,description,pages}]}`；`LESSONS=[{id,unitId,title,goal,pages,steps}]`。step.kind 为 preview/explore/learn/question/expression/recap；文本字段 title/text/prompt/hint/explanation；question 有 answer（字符串）、choices（字符串数组，可选）、itemKey（由引擎生成）；explore.widget 为 `{type,...}`。各课至少六道 question，稳定 id 不依赖展示排序。

widget.type 支持 view、order、ruler、units、mass、multiply、code、angle、fraction、groups、match、net；各自默认值在 UI 提供，改变参数必须有可见输出。按浏览器原生输入检验触控和键盘，手机 320/390、平板 768/1024、桌面 1366，不横向溢出。

完成条件：全册原创教学与互动可用、首次答题/续学/复习/家庭同步有证据、三科入口可达、独立审查通过、构建与相关回归通过、部署并公开页面读取验证。
