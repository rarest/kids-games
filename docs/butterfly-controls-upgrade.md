# 蜜语花园：全页飞行与连续采蜜

方向键/WASD为相对于当前视线的前后左右移动，Q/E分别为左前/右前，斜向速度归一。J/L或屏幕转向按钮负责旋转视角。后退和侧移不强制转镜头；画布点击选目的地仍能自动转向飞行，拖动可自由环顾。空格无限加速，F合翅，C切换连续采蜜，V整包存蜜。摇杆中心死区过滤手指轻微抖动。
