# 微信英语课堂：开发版交付与正式接入

英语网页继续使用 https://games.nblord.com/games/english.html 。本次增加原生微信小程序代码，课程来自同一份照片教材，90页、36课。逐页听读、词句练习、跟读录音、回听及发音反馈均已接入。现有用户名账号可登录，并选择原来的孩子档案；访客可直接学习。

## 导入开发者工具

1. 在微信公众平台新建小程序账号，取得该小程序自己的 AppID。已有公众号和小程序是两个应用，不能直接将公众号 AppID 填到小程序项目中。
2. 安装微信开发者工具，将本仓库的 `miniprogram` 文件夹作为项目目录导入。没有小程序账号时，项目默认的 `touristappid` 用于开发预览；微信身份授权仍需真实 AppID。
3. 正式开发时把 `miniprogram/project.config.json` 的 `appid` 改为小程序 AppID。`miniprogram/config.js` 仅包含网站地址，不放 AppSecret。
4. 在平台后台设置允许请求、下载和播放课程资源的 HTTPS 域名 `games.nblord.com`。实际发布前需要后台接受该域名，并完成隐私指引中的录音用途配置、真机检查和平台审核。开发工具里临时关闭域名校验仅用于本地检查，不用于发布。
5. 启动预览，先以访客学习，再用已有家长用户名检查孩子档案、导学进度同步及切换。微信未配置时按钮明确显示未开通，不模拟登录成功。

课程 JSON、PNG和原有音频由网站提供，不打入主包。逐页练习记录按孩子保存在此设备；36课导学进度登录后与网页同步。访客导学记录可以主动导入空白孩子档案。另一个设备同时修改课堂位置时，由家长选择继续的位置，答题记录保留。

## 服务端配置

私密配置继续放在网站服务端的 `~/.config/games-platform/app.env`，不放到网页目录、源码仓库或小程序中：

- `WECHAT_MINI_APP_ID` / `WECHAT_MINI_APP_SECRET`：新建小程序的身份。
- `WECHAT_WEB_APP_ID` / `WECHAT_WEB_APP_SECRET`：网页登录对应的微信应用身份。
- `WECHAT_WEB_MODE=website`：微信开放平台的网站应用扫码登录。
- `WECHAT_WEB_MODE=official-account`：公众号网页授权。先在公众号后台「接口权限」确认网页授权能力；订阅号、服务号及认证状态不能靠账号名称判断。

小程序登录与网页登录分别配置，不以公众号已经登录推定两者可用。未配置身份时，对应微信登录入口保持关闭；配置后用 `/api/miniprogram/config` 的 `wechatReady` 和 `webWechatReady` 分别核对。AppSecret 只写入服务器私密配置文件，不发送到聊天或客户端包。

网页家长中心在配置可用时显示微信登录和显式绑定入口。公众号授权入口在微信内打开；网站应用扫码入口使用微信开放平台。账号绑定要求刚完成登录，同一微信身份不能绑定两个家庭。系统不根据昵称或微信资料中的邮箱自动合并账号。没有绑定前，网页授权与小程序授权可能建立不同家庭，家长应使用已有用户名登录后主动绑定。

## 构建与验证

在仓库根目录运行：

```sh
npm ci
npm run build:miniprogram
npm run check:miniprogram
npm run test:miniprogram
```

官方编译器包的 Linux 文件是 x64 可执行文件。ARM机器需用不需要管理员权限的 QEMU运行器；`MINIPROGRAM_COMPILER_PREFIX` 接受 JSON格式的命令参数数组，作为编译器前缀。编译验证包括所有WXML/WXSS、JavaScript语法和实际教材数据驱动的页面分支。

后端测试使用独立 PostgreSQL 数据库，设置 `PLATFORM_TEST_DATABASE_URL` 后串行运行微信、用户名及家庭账号测试。仅远端腾讯授权响应使用测试替身；会话、数据库、家庭隔离和进度使用真实实现。实际微信扫码、真机麦克风和正式发布需在申请完成并配置好平台身份后验证。

服务端与开发版代码已区分部署：原生项目文件不放在网页公开目录；远程教材、插图和音频按网站公开资源部署。原有用户名注册继续要求6—64个字符，不需要邮箱验证。
