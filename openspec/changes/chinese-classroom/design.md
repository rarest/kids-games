## Context

当前主线6f1a5bb。英语使用静态ES模块、共享账号与孩子档案、PostgreSQL事件回放存档。英语云同步已有离线多标签页队列、CAS冲突处理和访客导入，沿用其可靠行为。用户已确认共用课堂和档案、学科隔离、小目标学习，并授权继续制作；最新名称为珠珠课堂。

## Goals / Non-Goals

目标：完整教材内容的语文课程及统一入口，保护既有英语进度和多设备可靠性。
非目标：本轮不实现数学课程，不接入语文AI发音评分，不发布教材照片上的个人信息，不重构英语探险游戏。

## Decisions

- 统一外壳使用 shared/classroom-nav.js，英语和语文独立地址并链接互通；games/classroom.html 是学科首页。比复制英语为语文更安全；比合并大型应用为单个运行时更少影响已发布功能。
- chinese/curriculum.js 定义单元与课文页码；正文和配套内容分单元静态数据。教材页码、印刷原文、识写字表与原创教学引导分字段；提供来源核对记录。OCR仅作转录草稿，人工看图核对才作为课程正文。
- chinese/engine.js 使用确定性步骤ID与存档加载验证。看图、短段阅读、字词释义、字词和理解题、表达、按要求背诵。错答后提示再试，完成必须满足所有步骤；自评仅记尝试。
- 英语云同步添加可选 subject/contentVersion/存档键参数，默认值和英语API不变。语文使用 pearl-chinese-course-v1 与 pep3-cn-2026-v1。
- 家庭服务使用学科白名单编解码器，增加 chinese API；数据库CHECK约束新增语文版本和学科，历史事件按content_version隔离，访客导入按学科检查空档案。导出包含两科。禁止接受任意学科字符串。
- UI采用温暖纸面、清晰分区、插画、单任务卡；手机单列、平板触控优先、电脑目录和正文两栏。图片优先可维护的原生SVG场景；不上传原始教材图片。

## Risks / Trade-offs

教材批注遮挡或OCR误读 → 看图核对印刷原文，记录具体校对进度，不把未核对内容发布。
切换或迟到的云请求串档 → 使用既有云同步generation和各孩子存档键，测试迟到响应、离线恢复、两科交替。
中文多音字 → 词语按上下文标注拼音，听读先准备固定音频；设备朗读只作为明确提示的备用，不声称已评分。
数据库约束迁移 → 事务内重复可执行，只扩展允许值；回滚应用保留新数据，不删孩子或清空表。

## Migration Plan

先内容与存档单元测试，再真实数据库两科并发隔离与三端浏览器验收，再独立审查、合并主线、既有webhook部署。核对公网资源和两科学习路径后报告交付。游戏运行时无变更，不重启联机游戏。
