## Context
上版的实际移动和尾迹切断已连续，但轮廓基于格子边缘，角色是折角纸片，定位图仍画方块。参见 proposal.md。
## Goals / Non-Goals
地图对象外轮廓只使用圆形与圆弧；既有 60 款皮肤纹理仍保留于圆形角色内部，其他游戏不受影响。
## Decisions
- 随机岛屿的行动边界采用一个大圆，内部叠加多个大小圆形区域呈现圆弧层次。圆心、半径随种子变化；保持外部大圆凸性，避免凹边让逻辑相邻格无法互通。逻辑格子中心采样同一圆形几何，移动验证真实圆形边界，手工规则测试仍可使用自定义地图。
- 领地根据至空格的精确距离生成由大到小的圆覆盖。圆覆盖所有有效格子中心，不包含任何非己方格子中心，并保留细连接带；不显示网格。
- 圆形角色共用渲染入口，纹理圆形裁剪，使用球形高光、阴影和圆形光粒。透明尾迹继续沿真实路线，圆帽、圆连接及圆点；切线逻辑不变。
- 圆形定位图采用均匀投影及圆点摘要；当前位置与附近视野用圆点和圆环表现。底图和距离计算仅在领地变化时缓存。
## Risks / Trade-offs
- 圆覆盖计算增加开销 → 线性距离变换、贪心覆盖与缓存，并检查大地图性能。
- 轮廓与逻辑网格的边缘有亚格差异 → 保证格子中心归属一致，岛屿移动另检验真实圆形几何，回归连接和切线。
## Migration Plan
测试、截图和审查后通过既有 webhook 部署，核对版本资源和真实公网游玩；存档键不变。
