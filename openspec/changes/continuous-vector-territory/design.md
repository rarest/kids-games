## Context
原生产引擎以格中心记录归属，圆覆盖和圆点地图是近似。用户要求实际轨迹与真实地盘、彻底无台阶的边缘，并要求人物和领地材质相同。
## Goals / Non-Goals
生产引擎不加载旧格引擎。沿真实坐标裁剪、渲染及计面积；保留60款皮肤、普通与精致购买、本机存档及其他游戏；隐藏皮肤改为全岛胜利后触碰宝箱直接赠送。
## Decisions
- core.js 使用连续点、多边形与实际线段切断，polygon-clipping 固定版本作为快速裁剪、polyclip-ts 固定版本加1e-12精度作为退化几何备用，一并打包为本地 ESM。真实外圈为随机波浪凸凹的平滑闭合曲线，等大起始领地为圆。旧逻辑移到 legacy-core.js，历史规则测试保留，不进入生产依赖。
- 每段移动按所有实际边界交点顺序分段，薄残片不依赖端点采样；离开己方地盘记录实际退出点，返回时由真实尾迹与己方边界路径形成封闭区域；新旧区域并集后从敌方区域做差。断开的己方区域只能增加实际连接带，不假造封闭内部。自交子环暂存，切线丢弃本次扩张。
- 占地百分比只统计真实多边形面积，不控制填充形状。外圈碰撞和贴边运动只使用实际连续轮廓，不查询格子。
- 渲染缓存真实区域路径和材质。人物及领地共用材质纹理；精致款具细密纹理和少量光粒，隐藏款共用动态图案、银河流星和3秒星光运动尾迹。普通款保持纯色。
- 小地图完全清空背景，只用固定全岛坐标投影己方区域形状，仅增加单个己方位置标记，不绘制点格、敌人或视野圈。定位数据仍可用于诊断。
- 人机在14单位有限视野内选择敌方尾迹真实截击点，按原速度追击；尾迹消失或自身风险过高后步行返回再扩张。
- 每次全岛胜利后停止对抗，散落60枚金币（每枚5）及120度分散的3个宝箱；每箱直接赠予随机未拥有的隐藏款，全部已拥有后改赠50金币。触碰物体才记账，存档以领奖收据及结算局号防重复。旧已拥有隐藏皮肤保留；累计胜场不再解锁购买。默认4.5单位/秒，标准6.2单位/秒，均较旧选项适度提高。
## Risks / Trade-offs
- 布尔几何可能复杂 → 固定本地组件、4096点上限与亚像素RDP简化保留转角，限制尾迹记录、仅在捕获/自交时执行裁剪；以凹形、桥接、自交、区域孔洞及重复操作测试验证。
- 材质和动态开销 → 缓存纹理和地图，限制光粒与星尾数量，验证暂停、减少动画及大地图帧耗时。
## Migration Plan
沿用当前生产存档键。统一新资源版本，完整项目检查和独立审查后部署，核对资源及公网实际操作。
