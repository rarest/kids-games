## Context

现有射击控制器基于 Canvas 与离散帧更新，浏览器需要用户手势后才能播放声音。

## Goals / Non-Goals

提供舒缓背景与清晰战斗声音，保持帧更新轻量。

## Decisions

使用单个 Web Audio 上下文；原创四和弦环境音与有变化的旋律通过短前瞻调度播放。音效独立音量，连续击中节流，活动声部上限 40。敌人生命值减少或积分增加触发命中音，护盾减少触发受伤音。游戏结束停止音乐，允许最后的短音效自然结束；暂停、静音、失焦、后台停止全部音源与调度。异步解锁完成后再次检查当前播放状态。声音不可用时游戏继续。

## Risks / Trade-offs

浏览器手势限制通过真实触摸测试验证；不在页面加载时主动播放。

## Migration Plan

更新射击入口脚本版本，提交合并后沿用已有 webhook 发布，核对新域名资源与线上音频行为。
