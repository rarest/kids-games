## Why

皇冠迷宫在手机和平板上存在背景音乐循环断点明显、操作音效被移动浏览器拦截、滑动时出现系统选区，以及持续运行后因高成本全画布重绘而明显卡顿的问题。这些问题直接影响核心游玩体验，需要以跨设备可验证的方式统一修复。

## What Changes

- 将背景音乐升级为不少于 60 秒、包含多个差异化段落且首尾无静音断点的皇家花园风格循环音乐。
- 将短操作音效改为首次用户手势统一解锁、预解码并复用缓冲区的播放模型，同时提供移动 Safari 可用的兼容音频格式与安全降级。
- 禁止游戏交互区域产生文字选择、长按菜单和原生拖拽，避免滑动手势触发蓝色系统选区。
- 缓存墙体、墙影和固定装饰等静态绘制层，仅在关卡、视口或可破坏墙状态变化时重建；动态元素保持独立绘制。
- 为手机、平板和桌面采用与设备能力匹配的受控帧率，并在交互后立即安排绘制，兼顾流畅度与功耗。
- 增加音频解锁、循环接缝、触控选区、静态层缓存和长时间运行性能回归测试。

## Capabilities

### New Capabilities

- `crown-maze-audio`: 规定背景音乐的无感循环、操作音效解锁、格式兼容、音量控制和生命周期行为。
- `crown-maze-touch-interaction`: 规定手机、平板和桌面指针操作期间不得触发浏览器选择或原生拖拽界面。
- `crown-maze-render-performance`: 规定静态场景缓存、动态绘制调度、资源上限和持续运行性能要求。

### Modified Capabilities

无。

## Impact

- 主要影响 `maze/audio.js`、`maze/main.js`、`maze/render.js`、`maze/game.css`、背景音乐生成脚本和音频资源。
- 需要扩展 Node 单元测试、真实浏览器手机/平板测试及性能诊断接口；不改变存档格式、关卡数据、金币与商店规则。
- 可能新增浏览器原生 Web Audio API 的适配代码以及 MP3/AAC 兼容资源，不引入运行时第三方依赖。
