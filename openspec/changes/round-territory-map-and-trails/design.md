## Context
参见 proposal.md。引擎已有连续坐标，但轨迹只记录格子中心，渲染直接绘制矩形。闭合算法要求起终点间存在己方领地路径，遇到两块分离领地会取消扩张。

## Goals / Non-Goals
实现用户要求的圆润探索和重新连接；保持存档、皮肤和原有游戏行为，不引入新经济规则。

## Decisions
- 游戏采用 88×76 世界，保留核心可配置尺寸以兼容规则测试。相机居中跟随玩家，按屏幕比例显示有限区域；鼠标通过当前相机转换为世界目标，摇杆保持任意角度模拟方向。
- 将格子并集提取为闭合轮廓，再平滑渲染。逻辑网格继续计算占比和围地，视觉不显示方块拼接。连续实际坐标单独记录轨迹，去除共线点、超过预算时简化，切断/回家即清空。
- 世界底图在领地变更时缓存，小地图使用粗块显示整岛、各方颜色、位置和当前视野；逐帧只更新角色、轨迹、视野标记，避免大地图每帧重绘。
- 两块己方领地没有内部连接路径时，占下实际穿过的连接带及已闭合子区域，不虚构包围面积或额外清空敌方剩余领地；实际划过暴露尾迹仍切断本次扩张。

## Risks / Trade-offs
- 世界放大增加绘制和判定量 → 底图缓存、轨迹点预算、视野裁剪和模拟运行检查。
- 相机改变鼠标坐标 → 真实浏览器验证目标到达、视野跟随和各尺寸触摸。
- 逻辑离散化仍用于公平结算 → 外观轮廓平滑，移动/尾迹保持真实连续坐标，圆形围地用行为测试验证。

## Migration Plan
基于最新 main 隔离实现并保留原存档键；测试及截图通过后合并 webhook 发布、核对线上文件与实际浏览器。
